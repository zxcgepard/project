Telegram-бот «Кулинарный помощник»

Telegram-бот для генерации рецептов с использованием локальной нейросети **Ollama**.


О проекте

Этот бот помогает быстро придумать, что приготовить на ужин, десерт или любое другое блюдо. Он использует нейросеть, которая работает локально на сервере, поэтому бот не требует платных API-ключей и сохраняет конфиденциальность данных.


Функционал

- Генерация рецепта для ужина
- Генерация рецепта десерта
- Поиск рецепта по продуктам (например: *картошка, лук, яйца*)
-  Кнопки быстрого доступа под строкой ввода
-  Автоматическая очистка рецептов от лишних символов


Технологии

- **Python 3.10**
- **pyTelegramBotAPI** — работа с Telegram Bot API
- **Ollama** — локальный запуск нейросети
- **Docker** — контейнеризация бота и нейросети
- **GitHub Actions** — автоматический деплой (CI/CD)
- **Ubuntu 22.04** — серверная ОС
- **dotenv** — безопасное хранение токена



Как это работает

1. Пользователь отправляет запрос (текст или нажатие кнопки)
2. Бот передаёт запрос нейросети Ollama
3. Нейросеть генерирует рецепт на русском языке
4. Бот очищает ответ и отправляет пользователю
